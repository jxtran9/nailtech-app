# NailTech App

A full-stack web application for a nail salon that allows customers to request appointments and staff to manage bookings.

## Tech Stack
- Frontend: React (Vite)
- Backend: FastAPI (Python)
- Database: MySQL

## Features
- View available services
- Submit booking requests
- Admin dashboard for managing appointments
- Data analytics for business insights (in progress)

## Project Structure
- frontend/ → React UI
- backend/ → FastAPI API
- database/ → SQL schema and queries
